# ADR-0001: استفاده از PostgreSQL

## زمینه و مسئله
محصول به تراکنش، رابطه‌های پیچیده، تاریخچه، JSON محدود، Index و جداسازی Tenant در سطح سطر نیاز دارد.

## محرک‌ها
- سازگاری با RLS
- Constraint و تراکنش قوی
- Query تحلیلی و Index متنوع
- ابزارهای متن‌باز بالغ

## گزینه‌ها
1. PostgreSQL
2. MySQL/MariaDB
3. دیتابیس Document

## تصمیم
PostgreSQL دیتابیس اصلی است.

## پیامدهای مثبت
- RLS بومی و مدل رابطه‌ای مناسب
- JSONB برای بخش‌های محدود و انعطاف‌پذیر
- قابلیت رشد گزارش‌های تحلیلی

## پیامدهای منفی و ریسک‌ها
- RLS و Indexing به تخصص و تست نیاز دارد.
- استفاده بی‌رویه از JSONB می‌تواند مدل را مبهم کند.

## زمان بازبینی
پیش از انتخاب ORM یا اگر نیاز عملی به دیتابیس دیگری ثابت شد.
