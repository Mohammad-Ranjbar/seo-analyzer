# ADR-0009: Rule و Score Model نسخه‌دار

## زمینه و مسئله
تغییر Rule یا وزن امتیاز می‌تواند روند تاریخی را بدون تغییر واقعی سایت جابه‌جا کند.

## محرک‌ها
- مقایسه منصفانه در زمان
- قابلیت بازتولید گزارش
- توضیح تغییر امتیاز
- امکان انتشار تدریجی مدل جدید

## گزینه‌ها
1. ویرایش مستقیم Rule و وزن
2. ذخیره فرمول در Snapshot
3. Version immutable برای Rule و Score Model

## تصمیم
هر Crawl به نسخه دقیق Ruleها و Score Model متصل است. نسخه استفاده‌شده تغییر نمی‌کند و نسخه جدید رکورد جدید می‌سازد.

## پیامدهای مثبت
- Audit و بازتولید ممکن است.
- نمودار روند قابل تفسیر می‌ماند.

## پیامدهای منفی و ریسک‌ها
- تعداد رکورد و پیچیدگی Query بیشتر می‌شود.
- مقایسه بین دو Version نیازمند هشدار یا Recalculation است.

## زمان بازبینی
پس از طراحی نخستین Score Model واقعی.
