# ADR 0016 — مدل فیزیکی داده و چرخه‌های وضعیت

## تصمیم

قرارداد تولیدشدهٔ Prisma 8 و بستهٔ migration بازبینی‌شده، مدل فیزیکی قابل اجرا هستند. قیدهای PostgreSQL مقادیر وضعیت، شمارنده‌ها، بازهٔ امتیاز، ترتیب زمانی و nullability شرطی را enforce می‌کنند. کلیدهای خارجی ترکیبی هر رکورد tenantدار را به سازمان، workspace و پروژهٔ درست متصل می‌کنند. کلیدهای امنیتی روی جدول‌های واسط نیز تکرار می‌شوند تا RLS بدون اعتماد به joinهای برنامه قابل اعمال باشد.

UUIDها در برنامه ساخته می‌شوند و زمان‌ها، جز موارد دارای default صریح، توسط برنامه تعیین می‌شوند. موجودیت‌های قابل حذف ابتدا وارد وضعیت archive/deleting و سپس `deleted` می‌شوند؛ اجرای خاتمه‌یافته باید زمان پایان داشته باشد. درخواست حذف پیش از purge یک بازهٔ بازیابی دارد.

## پیامدها

- ERD مفهومی نمای دامنه است و قرارداد Prisma منبع حقیقت deploy است.
- مجوز transitionها در سرویس بررسی می‌شود و دیتابیس حالت نهایی ناسازگار را رد می‌کند.
- هر تغییر قرارداد نیازمند migration بازبینی‌شده و آزمون apply/verify روی دیتابیس خالی است.
