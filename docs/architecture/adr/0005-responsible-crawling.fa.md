# ADR-0005: Crawl محدود و مسئولانه

## زمینه و مسئله
تحلیل رقبا به دسترسی خودکار به سایت‌های عمومی نیاز دارد و Crawl کنترل‌نشده می‌تواند به سایت مقصد فشار وارد کند یا از حدود اعلام‌شده عبور کند.

## محرک‌ها
- احترام به انتخاب مالک سایت
- جلوگیری از Abuse و حلقه بی‌نهایت
- هزینه قابل کنترل
- قابلیت توضیح رفتار Crawler

## گزینه‌ها
1. Crawl نامحدود
2. تکیه صرف بر Sitemap
3. Sitemap/صفحه اصلی همراه Robots، Scope و Limit

## تصمیم
Crawler با User-Agent شفاف، رعایت robots.txt، Rate Limit، Backoff، Cache و سقف صفحه/عمق/زمان کار می‌کند. صفحات خصوصی یا عملیات تغییردهنده هرگز هدف نیستند.

## پیامدهای مثبت
- ریسک عملیاتی و اخلاقی کمتر
- مصرف قابل پیش‌بینی
- امکان توقف و Audit هر Run

## پیامدهای منفی و ریسک‌ها
- برخی سایت‌ها تحلیل ناقص خواهند داشت.
- Robots یا Sitemap خراب نیازمند رفتار محافظه‌کارانه است.

## زمان بازبینی
با تغییر استانداردهای Crawl یا اضافه‌شدن منبع داده رسمی.
