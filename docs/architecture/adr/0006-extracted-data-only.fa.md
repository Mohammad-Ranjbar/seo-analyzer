# ADR-0006: عدم ذخیره HTML کامل

## زمینه و مسئله
ذخیره HTML کامل هزینه، ریسک حقوقی و سطح داده حساس را افزایش می‌دهد، در حالی که مقایسه به مجموعه محدودی از فیلدها نیاز دارد.

## محرک‌ها
- کمینه‌سازی داده
- کاهش فضای ذخیره‌سازی
- کاهش ریسک نگهداری محتوای رقیب
- حفظ امکان مقایسه تاریخی

## گزینه‌ها
1. ذخیره HTML کامل
2. ذخیره موقت HTML
3. ذخیره داده استخراج‌شده و Fingerprint

## تصمیم
فقط Metadata، Heading، Structured Data لازم، شاخص‌های لینک/تصویر، Status و Fingerprint ذخیره می‌شود. HTML کامل ذخیره نمی‌شود.

## پیامدهای مثبت
- Storage و سطح ریسک کمتر
- حذف ساده‌تر داده
- Snapshotهای کوچک‌تر

## پیامدهای منفی و ریسک‌ها
- Debug برخی Parserها بدون بازتولید Crawl دشوارتر است.
- استخراج‌نشدن یک فیلد در گذشته قابل بازیابی نیست.

## کنترل‌ها
- ثبت Version Parser و Rule
- Fixtureهای مصنوعی برای تست Parser

## زمان بازبینی
فقط در صورت نیاز اثبات‌شده و با سیاست Retention محدود.
