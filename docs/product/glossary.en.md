# Glossary

| Term | Definition |
|---|---|
| Organization | The primary business ownership, membership, and data-isolation boundary |
| Workspace | An organization area with independent members, roles, and projects |
| SEO Project | The unit that owns scope, properties, competitors, crawls, and reports |
| Property | A domain or subdomain belonging to the owner or a competitor |
| Scope | Structured market, product, objective, and analysis boundaries |
| Competitor | An approved competing business with one or more properties |
| Crawl Run | One independent crawl execution with status and usage metrics |
| Baseline | The first successful crawl used to measure progress |
| Snapshot | Extracted page or score data captured at a point in time |
| Finding | The result of evaluating a rule against a page or site |
| Action Item | A trackable recommendation derived from a finding or analysis |
| Verification | A later crawl's technical result for a reported issue |
| Rule Version | An immutable version of audit logic |
| Score Model | A versioned set of scoring weights and formulas |
| RLS | PostgreSQL row-level policies that restrict tenant-visible rows |
| BYOK | Using a user-owned API key for AI capabilities |
