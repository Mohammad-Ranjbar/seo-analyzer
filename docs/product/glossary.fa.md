# واژه‌نامه

| واژه | تعریف |
|---|---|
| Organization | مرز اصلی مالکیت، عضویت و جداسازی داده یک کسب‌وکار |
| Workspace | فضای کاری داخل سازمان با اعضا، Roleها و پروژه‌های مستقل |
| SEO Project | واحد تنظیم Scope، سایت، رقبا، Crawl و گزارش |
| Property | یک دامنه یا Subdomain متعلق به سایت کاربر یا رقیب |
| Scope | تعریف ساختاریافته بازار، محصول، اهداف و محدوده تحلیل |
| Competitor | کسب‌وکار رقیب تأییدشده با یک یا چند Property |
| Crawl Run | یک اجرای مستقل Crawl با وضعیت و آمار مصرف |
| Baseline | نخستین Crawl موفق که مبنای سنجش پیشرفت است |
| Snapshot | داده استخراج‌شده یک صفحه یا امتیاز در یک زمان مشخص |
| Finding | نتیجه اجرای یک Rule روی صفحه یا سایت |
| Action Item | اقدام قابل پیگیری که از Finding یا تحلیل ایجاد می‌شود |
| Verification | نتیجه فنی Crawl بعدی درباره رفع یا باقی‌ماندن مشکل |
| Rule Version | نسخه تغییرناپذیر منطق یک بررسی |
| Score Model | مجموعه نسخه‌دار وزن‌ها و فرمول‌های امتیازدهی |
| RLS | سیاست PostgreSQL برای محدودکردن سطرهای قابل مشاهده هر Tenant |
| BYOK | استفاده از API Key متعلق به خود کاربر برای AI |
